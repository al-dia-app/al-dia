# Al día

Descargas de Al día. Instrucciones: **https://scheduleer.app/al-dia/**

Proyecto estudiantil independiente, sin afiliación con Uniandes ni con D2L. Antes de
usar Al día en un curso, revisa su política de uso de IA.

Cada versión está en [Releases](../../releases/latest):

| Sistema | Archivo |
|---|---|
| Windows 10 u 11 | `al-dia-win32-x64.mcpb` |
| Mac con Apple Silicon | `al-dia-darwin-arm64.mcpb` |
| Mac con Intel | `al-dia-darwin-x64.mcpb` |
| Ubuntu o Debian con Claude Desktop | `al-dia-linux-x64.mcpb` (`-arm64` para ARM) |
| Arch u otro Linux con Claude Code | `al-dia-linux-x64.tar.gz` (`-arm64` para ARM) |
